# Project 03 — Network Traffic Analysis

## Problem
Two packet captures (`ssh_capture.pcap`, `test_capture.pcap`) from a
live Ubuntu VM. Goal: analyze them manually and document what the
traffic reveals about normal vs. potentially suspicious activity.

## Environment
- Oracle Cloud Ubuntu VM
- Wireshark / tcpdump
- Captures taken during active SSH session

## What I analyzed
Documented in `findings.md`:
- Protocol breakdown
- TCP handshake sequences
- Source/destination IPs and ports
- Observations on SSH negotiation behavior
